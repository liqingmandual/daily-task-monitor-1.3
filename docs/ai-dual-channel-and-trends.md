# AI 双通道、审核与趋势工作台

## 两种执行通道

应用提供两条互斥的 AI 执行通道：

- **API Key**：调用设置中选定的 OpenAI、智谱、硅基流动、ModelScope 或兼容接口。Key 只保存在 Windows Credential Manager。
- **本机 Codex**：启动设置中指定的 Codex CLI，由本机 Codex 环境完成请求；应用不会把它改写成 API 请求。

分类、工作流建议和趋势研究任务在**入队时**保存执行通道、提供商、模型和证据哈希。之后修改设置不会改变已经排队的任务。每次执行还会记录实际执行器、实际模型、耗时和清洗后的失败原因，供 AI 审核中心追踪。

两条通道之间没有自动回退。API 失败不会改用 Codex，Codex 启动失败也不会改用 API。这样可以避免在用户没有明确同意时改变数据去向或计算环境。

## 数据最小化

AI 请求使用完成当前任务所需的最小证据：安全摘要、时间范围、聚合统计、稳定证据 ID，以及分类或工作流所需的有限字段。应用不会把按键内容、鼠标轨迹、剪贴板、密码、Cookie、表单、音频或完整私有页面正文发送给 AI。

趋势研究只接收工作台生成的聚合证据。每条研究发现必须引用当前证据集合中的 evidence ID；证据不足时只显示限制说明，不生成无依据的观察或建议。

## 自动化与人工触发

设置中的三个开关彼此独立：

- 活动分类自动化
- 工作流建议自动化
- 趋势研究自动化

关闭某个自动开关只阻止该类后台自动入队，不影响另外两类任务。工作流和趋势页面的手动触发仍可使用，并按触发时的当前执行通道创建任务。

## 85% 分类规则

AI 分类置信度大于等于 `0.85` 时可以自动应用；低于 `0.85` 时进入待审核。因此 `0.85` 自动应用，而 `0.849999` 必须人工审核。

人工分类、人工接受替代值，以及撤销自动应用都会建立人工所有权。后续 AI 结果不能覆盖这些字段；撤销不是恢复为可被 AI 随意改写的状态。用户创建的分类规则仍优先于 AI。

## AI 审核中心

审核中心有四个主要页签：

- **待审核**：可接受建议、填写并应用替代值，或忽略建议。
- **已自动应用**：展示达到阈值后自动落库的结果；可撤销，撤销后建立人工所有权。
- **人工改写**：展示用户确认或改写后的记录。
- **执行失败**：展示清洗后的诊断，并提供两种重试方式。

“按原模式重试”沿用失败任务入队时保存的通道和模型快照。“按当前模式重试”创建新一代任务，使用此刻设置中的通道和模型。两者都不会静默回退到另一条通道。

## 趋势工作台口径

趋势区间可以选择任意连续 `1-366` 天，并按日、周或月分桶。周桶和月桶会在所选区间边界裁剪，不会把区间外数据计入结果。

九项指标为：监测时长、活跃时长、学习时长、空闲时长、切换次数、最长专注、分类覆盖率、已完成任务数、关联任务时长。

工作台始终计算三项默认比较基准：当前区间、上一等长区间、上月同期；还可以增加一个自定义基准。基准会同时显示有效日和缺失日，避免把“没有采样”误判为零活动。

点击图表分桶可查看任务下钻和原始证据表。已完成任务数与关联任务时长均来自同一批任务/证据关联，因此汇总、下钻和原始行保持一致。共享证据会明确标注，避免重复理解为独立采样。

趋势 Markdown 导出包含粒度、比较基准、任务统计、数据质量和 Evidence ID 段落。旧版趋势与日报导出仍保留原有内容。

## Codex 路径配置

默认可执行文件名是 `codex`。Windows 会检查应用安装目录和 PATH；macOS 还会检查 `~/.local/bin`、npm/pnpm、nvm、Volta、Bun、Homebrew 以及 ChatGPT 应用内置 CLI，因为从 Finder 启动的应用通常不会继承交互式 shell 的 PATH。

如果自动检测仍未命中，可以在设置中填写可执行文件的绝对路径，例如：

```text
C:\Users\<用户名>\AppData\Roaming\npm\codex.cmd
/Users/<用户名>/.local/bin/codex
```

也可以填写实际安装位置中的 `codex.exe`。保存后运行 Codex 健康检查；后台检查验证版本和登录状态，手动测试还会执行一次最小结构化推理，两者都不会改用 API 通道。Orbit 会在独立的临时工作目录中启动 CLI，不依赖应用从终端或 Finder 的哪个目录启动。

## 故障排查

- **找不到 Codex 或 Access denied / OS error 5**：确认路径指向真实的 Codex 可执行文件且当前用户有读取和执行权限；WindowsApps 别名可能被系统策略阻止。macOS 可运行 `command -v codex` 查看实际路径，并在设置中用绝对路径交叉验证。
- **Codex 健康检查成功但任务失败**：在“执行失败”页查看清洗后的诊断，确认本机 Codex 已登录、模型可用且工作目录可访问。
- **API 任务失败**：检查所选提供商、模型、Base URL、网络和 Credential Manager 中的 Key；应用不会尝试另一家提供商或 Codex。
- **切换通道后旧任务仍使用原通道**：这是预期行为。使用“按当前模式重试”才会按新设置创建任务。
- **趋势只显示限制说明**：扩大日期范围、等待产生有效活动数据或改善分类覆盖率；缺少证据时不会生成研究结论。
- **自动任务没有创建**：确认对应的独立自动化开关已开启。手动触发不依赖该开关，但仍需要所选通道配置可用。
