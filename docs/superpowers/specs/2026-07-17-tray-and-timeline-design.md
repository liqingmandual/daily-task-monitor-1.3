# 活动时间线倒序、托盘双击与 Windows 图标设计

## 目标

- “活动时间线”始终以最新记录在上、最早记录在下的倒序展示。
- 左键双击 Windows 右下角托盘图标时，立即显示并聚焦主面板。
- 窗口、任务栏、托盘和安装包使用同一套现有应用 Logo，避免 Windows 底栏显示空白图标。

## 设计

### 时间线排序

前端在筛选活动后按 `startMs` 降序排序，不依赖数据库返回顺序。开始时间相同时依次按 `endMs` 降序和记录 ID 排序，保证结果稳定。筛选、AI 审核入口和手动分类行为保持不变。

### 托盘交互

Rust 桌面层增加一个复用的“显示主面板”函数，执行：

1. 获取 `main` 窗口。
2. 显示窗口。
3. 取消最小化。
4. 将窗口置于前台并获取焦点。

托盘菜单“打开表盘”和托盘左键双击都调用该函数。单击不打开窗口，右键仍保留原菜单行为。

### 应用图标

Tauri 产品配置显式声明现有 `src-tauri/icons` 中的 PNG、ICO 和 ICNS 资源。运行时窗口和托盘继续使用应用默认图标，从同一配置来源读取。安装包不增加新的外部资源，也不修改用户数据路径。

## 错误处理

显示、取消最小化或聚焦失败时不使后台监测进程退出；托盘菜单仍可继续使用。窗口不存在时事件安全忽略。

## 测试

- 前端测试使用乱序活动输入，验证渲染顺序严格为最新到最早，且不修改传入数组。
- Rust 测试覆盖托盘事件判定：只有左键双击触发打开动作。
- 配置测试或构建验证确保应用图标资源被显式打包。
- 运行 Vitest、TypeScript/Vite 构建、Rust 格式检查和完整 Rust 测试。
- 构建 release 与 NSIS 安装包，检查 EXE 图标资源、版本、哈希，并更新本机稳定版。
