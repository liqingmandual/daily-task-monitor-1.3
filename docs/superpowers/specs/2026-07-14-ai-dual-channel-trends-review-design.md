# 每日任务监测系统：AI 双通道、审核中心与趋势工作台设计

日期：2026-07-14

## 1. 目标

本次改动在现有桌面版的活动监测、AI 队列、任务账本和趋势聚合之上增加三个相互独立但可协作的能力：

1. API Key 与本机 Codex 两种 AI 执行通道。
2. 任务归类和工作流归属的统一 AI 审核中心。
3. 以原始数据为主、AI 研究结论为辅的趋势分析工作台。

本次设计不恢复此前被回退的私人 Codex 后端方案。实现沿用当前 Provider Registry、SQLite 数据、任务账本和 Tauri 桌面架构。

## 2. 已确认的产品原则

- AI 全局执行方式为 `api-key | codex`，一次只选择一种。
- 不允许跨执行方式自动回退。
- 任务入队时锁定执行方式；之后切换只影响新任务。
- 趋势分析、任务自动归类、工作流归属建议三个自动化开关独立存在。
- 本次升级后，三个自动化开关默认开启，并在首次启动时集中说明数据边界和关闭入口。
- 所有手动触发始终可用，不受后台自动化开关影响。
- 任务归类和工作流归属使用统一的 85% 自动写入阈值。
- 人工修改拥有最高优先级，AI 不得自动覆盖。
- 趋势页采用“数据工作台”布局，原始数据和确定性统计优先于 AI 解释。
- 趋势 AI 采用研究型表达，不做人格、情绪或心理状态推断。
- 趋势 AI 建议只读，不自动创建任务。

## 3. 信息架构

主导航调整为：

`今日 | 趋势 | 工作流 | AI 审核`

### 3.1 今日

今日页继续承载当天事实数据：监控、活跃、空闲、学习、切换、最长专注、时间线、人工归类、每日目标和任务关联。

复杂 AI 审核不在今日页展开。时间线只显示轻量状态标记，点击后跳转到 AI 审核中心的对应记录。

### 3.2 趋势

趋势页改为完整数据工作台，按以下顺序排列：

1. 区间与粒度工具栏。
2. 原始统计摘要。
3. 单指标时间柱状图。
4. 多基准比较柱状图。
5. 时间桶下钻与原始数据表。
6. 应用、分类、任务和工作流分布。
7. 数据质量。
8. AI 研究结论。

### 3.3 工作流

工作流页继续管理项目、任务、进度、完成状态以及活动证据关联。页面显示 AI 归属状态，但低置信结果统一在 AI 审核中心处理。

工作流页保留“手动请求 AI 建议”命令。该命令会创建显式手动任务，并使用当前全局执行方式。

### 3.4 AI 审核

AI 审核中心包含四个页签：

- 待复核。
- 已自动处理。
- 人工覆盖。
- 执行异常。

支持按任务类型、执行通道、Provider、模型、日期和置信度筛选。

## 4. AI 双通道

### 4.1 API Key 模式

- 沿用现有 Provider Registry、Provider 优先级和自定义 OpenAI 兼容接口。
- API Key 继续保存在 Windows 凭据库。
- 仅发送当前任务所需的最小数据。
- 趋势分析发送聚合统计、比较基准、数据质量和证据 ID。
- 任务归类发送必要的应用标识、脱敏标题摘要和有限上下文。
- 工作流归属发送候选任务 ID、任务标题、必要预期产出和证据摘要。
- 不发送完整活动时间线、无关窗口标题或无关浏览记录。

### 4.2 本机 Codex 模式

- 默认自动检测 `codex` CLI，同时允许用户配置可执行文件路径。
- 设置页显示检测路径、版本、最近检测时间和状态。
- 每次执行记录来源、模型标识、耗时、退出码和截断后的错误诊断。
- CLI 不可用或执行失败时，任务保持在 Codex 通道内重试。
- 不允许自动切换到 API。

### 4.3 执行方式快照

AI 任务入队时保存：

- `executionMode`。
- Provider 或 Codex 标识。
- 模型。
- 证据哈希。
- 生成版本。
- 创建时间。

切换全局执行方式不会修改已排队任务。审核中心提供“改用当前方式重新执行”，该操作创建新一代任务并使旧结果失效。

## 5. 设置 UI

设置继续使用右侧抽屉。AI 区域分为三段。

### 5.1 执行方式

使用 `API Key | 本机 Codex` 分段控件。状态区域显示可用、未配置、检测失败、权限受限或最近执行异常。状态同时使用图标和文字，不只依赖颜色。

### 5.2 Provider 与 Codex 健康检查

API Provider 行显示配置状态、模型、优先级和测试按钮。Codex 行显示 CLI 路径、版本、检测时间、重新检测按钮和路径配置入口。

### 5.3 自动化

显示三个独立开关：

- 趋势自动分析。
- 任务自动归类。
- 工作流归属建议。

升级后第一次启动显示一次说明弹窗，内容包括当前执行方式、会使用的数据类型、资源消耗、失败不回退规则和三个关闭入口。

## 6. 归类与工作流审核规则

### 6.1 自动写入

置信度 `>= 0.85` 时允许自动写入。自动写入记录必须保存原值、新值、证据摘要、置信度、执行方式、Provider、模型和生成时间。

### 6.2 待复核

置信度 `< 0.85` 时不得修改正式数据，结果进入待复核页签。记录展开后显示候选结果和每个候选的分数。

用户可以接受、改选或忽略。批量接受只允许处理相同记录类型，并在提交前显示数量确认。

### 6.3 人工覆盖

用户修改归类或工作流归属后，该字段获得人工所有权。后续 AI 结果可以作为参考记录保存，但不得自动覆盖。

用户可以主动解除人工锁定；系统和 AI 不得自动解除。

### 6.4 撤销自动写入

已自动处理页签允许撤销单次 AI 写入。撤销恢复写入前的值，并将恢复后的字段标记为人工所有，避免相同建议再次自动写入。

## 7. 趋势数据工作台

### 7.1 区间与粒度

- 预设区间：近 7 天、近 30 天。
- 自定义区间：最长 366 个日历日。
- 粒度：日、周、月。
- 默认粒度按区间长度选择，用户手动选择后在当前会话内锁定。

### 7.2 指标

时间柱状图一次显示一个指标：

- 监控时长。
- 活跃时长。
- 学习时长。
- 空闲时长。
- 切换次数。
- 最长专注块。
- 分类覆盖率。
- 任务完成数。
- 已关联任务时长。

### 7.3 原始统计

统计区显示：

- 总量。
- 日均或周均。
- 中位数。
- 最大值。
- 波动系数。
- 有效采样天数。
- 缺失天数。
- 分类覆盖率。
- 低置信时长。
- 待处理时长。

统计区采用紧凑行式布局，不使用大型卡片墙。

### 7.4 时间柱状图

柱状图按选择的粒度分桶。点击柱子后保持高亮并过滤下钻区域和原始表格。悬停显示准确数值、桶范围、数据完整度和任务完成数。

### 7.5 多基准比较

默认比较：

- 当前区间。
- 上一等长区间。
- 上月同期。

自定义基准默认关闭，启用后显示第四组。上月同期按当前起止日期整体向前一个日历月移动；遇到目标月份不存在的日期时，日期截断到目标月份最后一天，同时保持起止顺序。

比较使用并列柱。每组同时显示绝对差和百分比差。基准为零时显示“无有效百分比基准”，不显示无限大或误导性百分比。

### 7.6 下钻与原始表

点击时间桶后显示：

- 应用和分类分布。
- 任务完成情况。
- 已关联任务时长。
- 工作流归属。
- 数据完整度。

原始表支持日期、时间桶、应用、分类和任务筛选。柱状图与表格双向高亮。

## 8. AI 研究分析

趋势 AI 使用“观察、可能解释、验证方法”结构。

每条研究项包含：

- 观察：可由数据直接验证的事实。
- 可能解释：明确标记为假设，不作为事实展示。
- 验证方法：建议下一个观察周期继续记录或比较什么。
- 证据：指标、时间桶、比较基准和证据 ID。
- 置信度。
- 限制：样本量、缺失数据和分类覆盖率的影响。

AI 可以自由组织文字，但所有数值、变化方向和证据 ID 必须通过后端校验。未通过校验的条目不进入正式分析。

数据不足时只显示限制说明，不生成推断性解释或行为建议。AI 研究项只读，不提供“转为任务”，也不自动改变目标和计划。

## 9. 后端边界

实现应形成四个职责清晰的模块：

- AI 执行器：API 与 Codex 的统一结构化接口。
- AI 队列：入队、执行方式快照、租约、重试、超时和审计。
- 趋势聚合器：只计算事实数据。
- AI 结果校验器：验证候选对象、证据引用、数值和变化方向。

数据流为：

`原始活动和任务账本 -> 确定性聚合 -> 最小化 AI 输入 -> AI 输出 -> 后端校验 -> 自动写入或复核 -> 审计记录`

AI 结果写入前必须验证证据哈希和生成版本。数据在执行期间发生变化时，旧结果不得写入。

## 10. 错误处理

- API 与 Codex 使用明确超时和有限次数重试。
- 重试只发生在任务锁定的执行通道内。
- 不可恢复错误进入执行异常页签，不无限重试。
- 错误类型区分 CLI 不可用、API 鉴权、网络、响应格式、证据校验和数据过期。
- 诊断信息不得包含 API Key、完整提示词或敏感窗口标题。
- 部分 AI 条目无效时，只保留通过校验的条目；全部无效时任务失败。

## 11. 兼容性

- 现有趋势查询和 Markdown 导出继续可用。
- 新增响应字段使用向后兼容默认值。
- 现有 Provider 配置和 Windows 凭据不迁移、不删除。
- 现有用户数据库、历史记录和任务账本不重置。
- 不在项目目录重新生成大型 Rust `target`；继续使用已配置的 AppData 构建缓存。

## 12. 验收测试

### AI 通道

- API 与 Codex 分别成功执行并记录来源。
- 入队后切换全局方式不改变旧任务。
- 失败不会自动跨方式回退。
- 健康检查区分未配置、不可用和权限失败。

### 自动化与审核

- 三项开关互不影响。
- 手动触发在开关关闭时仍可用。
- 0.85 自动写入，0.849999 进入复核。
- 人工修改阻止后续 AI 覆盖。
- 撤销自动写入后建立人工所有权。

### 趋势

- 任意 1 至 366 天区间可查询。
- 日、周、月分桶边界正确。
- 上一等长、上月同期和自定义基准正确。
- 零基准、缺失天数和无记录区间显示明确空状态。
- 任务完成数按 `completed_at` 归集。
- 已关联任务时长与账本证据一致。
- 柱状图、下钻和原始表返回相同数据集合。

### AI 研究结论

- API 输入不包含完整活动时间线和无关窗口标题。
- 每条正式结论包含有效证据 ID。
- 数值和变化方向不一致的条目被拒绝。
- 数据不足时只输出限制说明。
- 趋势建议不能自动创建任务。

## 13. 非目标

- 不恢复已回退的私人 Codex 后端和主题升级。
- 不提供 API 与 Codex 自动故障切换。
- 不根据活动数据推断人格、情绪、疾病或心理状态。
- 不让趋势 AI 自动创建任务或修改目标。
- 不新增云端账户、同步或多人协作功能。
